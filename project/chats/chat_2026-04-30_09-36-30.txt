### What is Linear Search?

Linear search (also known as sequential search) is the simplest searching algorithm. It sequentially checks each element of the list until a match is found or the whole list has been searched.

**How it works:**

1.  Start from the first element of the list.
2.  Compare the current element with the target value you're looking for.
3.  If they match, you've found it! Return the index or indicate success.
4.  If they don't match, move to the next element and repeat steps 2-3.
5.  If you reach the end of the list and haven't found the target, it means the item is not in the list.

### Time Complexity

Time complexity describes how the running time of an algorithm grows as the size of the input (usually denoted as 'n') grows. We typically use **Big O notation** to express this, as it focuses on the upper bound (worst-case scenario) or average case, ignoring constant factors and lower-order terms.

For linear search, let 'n' be the number of elements in the list.

1.  **Best-Case Time Complexity: O(1)**
    *   **Explanation:** The best-case scenario happens when the target element is the *first* element in the list. The algorithm finds it immediately after just one comparison.
    *   **Example:** Searching for '10' in `[10, 20, 30, 40]`.

2.  **Worst-Case Time Complexity: O(n)**
    *   **Explanation:** The worst-case scenario occurs when:
        *   The target element is the *last* element in the list.
        *   The target element is *not* present in the list at all.
    *   In both these situations, the algorithm has to check every single element in the list (n comparisons) before it can conclude whether the element is found or not found.
    *   **Example:** Searching for '50' in `[10, 20, 30, 40]` (not found), or searching for '40' in `[10, 20, 30, 40]`.

3.  **Average-Case Time Complexity: O(n)**
    *   **Explanation:** On average, if the element is present, it could be anywhere in the list. Assuming the target element is equally likely to be at any position, the algorithm would check roughly half of the elements ($n/2$) before finding it.
    *   Since Big O notation disregards constant factors, $n/2$ still simplifies to $O(n)$.
    *   **Example:** If you search for an element and it happens to be in the middle of a very long list.

### What is a Bernoulli Trial?

A **Bernoulli trial** (or a Bernoulli experiment) is a random experiment with only two possible outcomes, conventionally called "success" and "failure."

Here are the key characteristics that define a Bernoulli trial:

1.  **Two Possible Outcomes:** There are only two mutually exclusive outcomes. These are typically labeled "success" and "failure," but they could be "yes/no," "head/tail," "on/off," "defective/non-defective," etc.
2.  **Constant Probability of Success:** The probability of "success" (usually denoted as 'p') is the same for every trial. Consequently, the probability of "failure" is $1 - p$ (often denoted as 'q').
3.  **Independence:** Each trial is independent of previous trials. The outcome of one trial does not affect the outcome of any other trial.

### Examples of Bernoulli Trials:

*   **Flipping a fair coin:**
    *   Success: Getting a Head (p = 0.5)
    *   Failure: Getting a Tail (q = 0.5)
*   **Rolling a die and checking for a "6":**
    *   Success: Rolling a 6 (p = 1/6)
    *   Failure: Not rolling a 6 (q = 5/6)
*   **Testing if a randomly selected product from a manufacturing line is defective:**
    *   Success: The product is defective (p = probability of defect)
    *   Failure: The product is not defective (q = 1 - p)
*   **A student guessing the answer to a true/false question:**
    *   Success: Getting the answer correct (p = 0.5)
    *   Failure: Getting the answer incorrect (q = 0.5)

### Bernoulli Distribution

When we talk about the probability distribution of a single Bernoulli trial, it's called the **Bernoulli Distribution**. It has a probability mass function (PMF) that looks like this:

*   $P(X=1) = p$ (probability of success)
*   $P(X=0) = 1-p = q$ (probability of failure)

Where $X$ is a random variable that takes the value 1 for success and 0 for failure.

### Connection to Binomial Distribution

Bernoulli trials are the foundation for the **Binomial Distribution**. If you perform a *fixed number* of independent Bernoulli trials (say, 'n' trials), and you want to find the probability of getting a *certain number of successes* (say, 'k' successes) within those 'n' trials, you would use the Binomial Distribution.

In essence, a Binomial experiment is just a sequence of independent and identical Bernoulli trials.

Understanding Bernoulli trials is crucial because it simplifies the analysis of many real-world events where outcomes can be boiled down to a simple "yes" or "no" decision.
